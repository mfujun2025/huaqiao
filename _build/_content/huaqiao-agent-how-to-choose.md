中介是很多人在买房过程中接触最多、也最难判断的环节。**这篇文章不给任何机构名单**——既不给推荐，也不给黑名单。

原因很简单：机构会变化、个体从业者差异远大于机构品牌，而榜单式推荐对读者是有害的。所以这里给的是**核查方法**：怎么自己判断。

> 本文为核查方法整理，非机构评价、非消费建议。中介资质、收费标准、投诉渠道请以主管部门公示与合同约定为准。本站不与任何中介机构存在合作关系。

## 一、第一步：核查资质

中介服务涉及资质与备案要求。核查要点：

| 核查项 | 在哪查 | 说明 |
|---|---|---|
| 机构资质/备案 | 主管部门公示渠道 | 确认机构是否依法备案 |
| 从业人员信息 | 机构提供 + 主管部门查询 | 确认服务人员身份 |
| 经营场所 | 实地查看 | 是否有固定经营场所 |
| 投诉记录 | 主管部门公示（如公开） | 可作为参考 |

**实操建议**：不要只看名片和工牌。**要求对方提供机构名称与相关证照信息，并到主管部门公示渠道核对。**

## 二、第二步：问清四件事（签约前必须书面确认）

这四件事都要**在付费前**问清，并尽可能留下书面记录：

**第一件：服务费怎么收**
- 费率是多少？按成交价还是其他方式计算？
- 买卖双方各自承担多少？
- 什么时候收取（签约时/过户后）？
- **退费条件是什么**（比如交易未完成怎么办）？

**第二件：房源信息的来源**
- 这套房源是谁在委托？委托关系是什么？
- 房源信息（面积、朝向、楼层、产权情况）能否提供材料核对？

**第三件：你能提供什么服务**
- 具体服务内容（带看、居间、协助办理手续等）
- 服务边界（哪些事不在服务范围内）

**第四件：交易流程与时间安排**
- 各环节的顺序、时间预计
- 你需要准备什么材料

**原则**：**口头的承诺不算确认。** 要写进服务协议或合同条款。

## 三、第三步：交叉验证房源信息

房源信息失真是最常见的行业问题。**不要相信单一渠道的信息**：

| 要核实的信息 | 怎么核实 |
|---|---|
| 面积、户型、楼层 | 要求提供产权材料核对，实地测量 |
| 产权状态 | 到不动产登记部门查询权属与限制情况 |
| 价格 | 多渠道对比（房产平台挂牌、其他中介报价） |
| 房屋状况（噪音、采光、渗水） | 自己在不同时段实地看 |
| 学区、配套 | 查主管部门官方文件，不听口头说明 |
| 是否为"独家"房源 | 询问其他渠道是否也有该房源 |

**特别注意**：**产权状态一定要自己查。** 不能只依赖中介的口头说明。

## 四、第四步：观察行为模式（五条红线信号）

比资质更值得观察的是**行为模式**。出现下面这些情况，建议立即停止推进：

| 红线信号 | 为什么危险 |
|---|---|
| 催促你"今天必须定" | 压缩你的判断时间 |
| 拒绝提供书面条款或公示信息 | 信息不透明 |
| 承诺"资格能搞定""社保能补" | 涉及违规操作，后果由你承担 |
| 阻止你直接与卖方沟通 | 阻断信息渠道 |
| 要求把款项付给个人账户而非对公账户 | 资金安全风险 |

**通用判断原则**：**任何让你"不要多想、快点决定"的推动，都值得停下来。**

## 五、关于中介费的三个提醒

1. **费率可以协商**：服务费属于市场协商范畴，具体标准与承担方式在合同中约定。签约前谈清，不要签完再争。
2. **付费节点要明确**：什么时候付、付多少、交易未完成时怎么处理，都要写清楚。
3. **保留凭证**：所有付款都要有凭证，并确认收款主体。

## 六、自己保护自己的五件事

- [ ] 到主管部门公示渠道核查机构资质
- [ ] 服务内容、费率、退费条件写入书面协议
- [ ] 产权状态自己到登记部门查询
- [ ] 价格多渠道交叉验证
- [ ] 学区、配套、政策口径全部走官方渠道
- [ ] 款项支付到对公账户并保留凭证
- [ ] 所有沟通记录留存（文字、截图）
- [ ] 不签空白文件、不签未读完的文件

**最有价值的一条**：**不要把任何环节的判断权完全交给中介。** 中介提供信息和流程协助，但资格、产权、价格、政策这四件事，必须你自己核实。

## 常见问题

::faq
Q|花桥哪家中介比较靠谱？
A|本文不推荐、不评价任何具体机构。原因是机构与从业者会变化，榜单式推荐会带来误导。建议按本文四步自查：核查资质、问清服务条款、交叉验证房源信息、观察行为模式。
Q|中介费一般怎么收？
A|费率与承担方式属于市场协商范畴，以合同约定为准。建议在付费前问清：费率、计算基础、买卖双方各自承担多少、付费时间、以及交易未完成时的退费条件，并写入书面协议。
Q|怎么判断房源信息是不是真的？
A|多源交叉验证：面积/户型要求提供产权材料核对；产权状态到不动产登记部门自己查；价格对比多个渠道；房屋状况自己实地看。不要依赖单一渠道的口头说明。
Q|中介说能帮我搞定购房资格，可信吗？
A|购房资格认定是主管部门的行政程序，第三方无权决定结果。声称"能搞定"的说法风险很高，若涉及虚假材料，责任由购房人承担。建议自己到官方渠道确认条件。
Q|能不能绕过中介直接和卖方交易？
A|这涉及合同关系与法律关系，需视具体情况判断，本文不给建议。可以确认的是：无论通过何种方式交易，产权查询、资金安全、合同条款这三件事都必须自己把控。重要条款建议咨询专业法律意见。
Q|中介要求付款到个人账户怎么办？
A|付款应支付到合同约定的对公账户，并保留全部凭证。要求付款给个人账户属于需要高度警惕的信号。建议立即停止推进，并核实收款主体的合法性。
::

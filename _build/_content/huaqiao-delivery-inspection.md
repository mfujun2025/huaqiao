收房（交付）是购房流程里**信息最密集、也最容易被情绪影响**的一天。现场通常时间有限、人多事杂，如果没提前准备清单，很容易看完一圈什么都没记住。

所以最好的做法是：**提前把清单打印出来，一项一项打钩。**

> 本文为交付验收的方法整理，非工程质量鉴定意见。房屋质量问题的认定与处理请以专业机构检测、合同约定与主管部门规定为准。

## 一、交付当天必须核对的文件

除了看房，交付时通常需要核对以下文件（具体清单以合同约定与主管部门要求为准）：

| 文件 | 核对什么 | 为什么重要 |
|---|---|---|
| 交付通知书 | 交付时间、地点、需携带材料 | 确定流程与时间 |
| 房屋竣工验收相关文件 | 是否具备交付条件 | 判断能否交付 |
| 面积实测数据 | 实测面积与合同约定面积的差异 | 涉及可能的补差 |
| 住宅质量保证书 | 保修范围与期限 | 后续维权的依据 |
| 住宅使用说明书 | 使用注意事项 | 避免装修损坏 |
| 物业相关文件 | 物业费标准、服务内容 | 明确后续费用 |

**关于面积差异**：实测面积与合同约定面积可能存在差异，处理方式通常以合同约定为准。**当场核对实测数据与合同数字，是必须做的一步。**

## 二、验房清单（可打印，逐项打钩）

### 结构与环境
- [ ] 墙体、顶面是否有明显裂缝（注意区分表面裂纹与结构性裂缝）
- [ ] 墙面是否有渗水痕迹、霉斑
- [ ] 地面是否起砂、空鼓（可轻敲听声音）
- [ ] 层高与合同约定是否一致（可带卷尺实测）
- [ ] 门窗开启是否顺畅、密封是否良好、玻璃是否有破损
- [ ] 阳台、卫生间、厨房的防水是否有渗漏迹象（查看楼下或做闭水试验）

### 水电
- [ ] 各房间插座是否通电（带一个可插的小电器或有测电笔）
- [ ] 开关是否控制对应灯具
- [ ] 配电箱是否标识清晰、是否有漏电保护
- [ ] 给水管通水是否正常、水压是否够、有无渗漏
- [ ] 排水管是否通畅（往地漏倒水测试）
- [ ] 燃气管道是否按规范敷设（不要自行改动）

### 精装房额外项（如适用）
- [ ] 装修材料与合同约定清单是否一致（品牌、型号、数量）
- [ ] 地板是否有空鼓、翘边
- [ ] 瓷砖是否有空鼓、破损、色差
- [ ] 橱柜、卫浴安装是否牢固、使用是否正常
- [ ] 门锁、五金件是否正常
- [ ] 是否存在未完工项（如收边、打胶未完成）

### 公共部分与配套
- [ ] 电梯是否正常运行
- [ ] 楼道、公共区域是否完工
- [ ] 承诺的配套设施当前状态（已交付/仍在施工）
- [ ] 车位是否可用、车位配比的实际交付情况

## 三、发现问题怎么办：正确顺序

发现问题是正常的（交付几乎不可能完美），关键是**处理顺序**：

1. **当场记录**：拍照（带时间）、视频、写在验收单上。**不要只口头说。**
2. **书面确认**：要求在交付验收单上注明问题，双方签字。**这是后续处理的依据。**
3. **明确整改期限**：问清整改的时间安排，并**要求书面记录**。
4. **保留全部材料**：通知书、验收单、照片、沟通记录。
5. **整改后复验**：按约定时间复验，确认问题解决。
6. **如涉及面积差异或重大质量争议**：按合同约定处理，必要时寻求专业检测机构或主管部门协助。

**关键原则**：**不要在没有记录问题的情况下签收。** 一旦签收单据未注明问题，后续主张会困难很多。

## 四、延期交房怎么办

如果开发商未按合同约定的时间交付，处理思路是：

1. **核对合同条款**：合同通常约定交付时间与延期责任。这是你的主要依据。
2. **取得书面说明**：要求开发商提供延期的书面通知与原因。
3. **计算实际损失**：延期期间的租房成本、通勤成本等（视具体情形与合同约定）。
4. **按合同主张权利**：按约定条款主张违约金或相应责任。
5. **必要时通过法律途径**：金额较大时咨询专业法律人士。

**注意**：合同中常会约定"因不可抗力等原因可延期"的条款，因此**判断时需要区分延期原因**。具体定性请咨询专业意见。

## 五、收房当天的时间安排建议

- **提前一天**：把清单打印好，准备好工具（卷尺、测电笔/小电器、手电、手机充电宝、纸笔）。
- **当天**：先核对文件（第一节），再按清单验房（第二节），**发现问题当场记录并签字确认**。
- **不要急于签收**：给自己留足时间，不要被人催着签。
- **带上懂行的人**：如有装修或工程经验的朋友，一起看会更有帮助。
- **复杂情况请专业验房服务**：如果房屋情况复杂或金额较大，考虑请专业机构协助。

## 常见问题

::faq
Q|交房验收要注意什么？
A|三件事最关键：一是核对交付文件（竣工验收文件、面积实测数据、质量保证书）；二是按清单逐项检查并在发现问题时当场记录；三是不要在未注明问题的情况下签收。书面记录是后续处理的唯一依据。
Q|精装房怎么验收？
A|除了常规项（墙体、水电、门窗），还要核对装修材料与合同约定清单是否一致（品牌、型号、数量），检查地板空鼓、瓷砖破损、橱柜卫浴安装、门锁五金等，并确认是否存在未完工项。
Q|发现质量问题不签收可以吗？
A|遇到问题应先在验收单上注明并双方签字确认，同时要求书面整改期限，而不是简单拒签。一旦签收但未注明问题，后续主张会困难。具体处理方式建议按合同约定并咨询专业意见。
Q|延期交房怎么处理？
A|先核对合同中的交付时间与延期责任条款——这是主要依据；要求开发商出具书面延期说明；按约定主张权利。注意合同中通常有关于不可抗力等情形的约定，延期原因的定性建议咨询专业法律意见。
Q|收房要带什么工具？
A|卷尺（量层高、开间）、测电笔或可插的小电器（测插座）、手电（照管道与角落）、纸笔（记录）、手机（拍照留证）。加上本文的打印清单。
Q|物业费从什么时候开始交？
A|物业费的起算时间通常以合同约定或交付时间为基础，具体以物业服务合同与相关规定为准。收房时建议一并问清物业费标准、缴纳方式与起算时间。
::
